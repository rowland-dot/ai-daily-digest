Subscribe form — 5 states

The footer subscribe banner (Variant A) lifecycle. Each card shows the form in one state, with realistic copy. Test IDs preserved from per-state mockups 01–05.

1. Idle (resting)

Entry point

Email field empty, submit button enabled, no message row.

2. Submitting

Transition

User clicked Subscribe. Input + button disabled. Spinner in button. aria-busy="true".

3. Link sent (success)

Success

Magic-link email dispatched. Form replaced with success message; email shown.

✓ Check your inbox. We sent a confirmation link to alex@example.com. Click it to finish subscribing — the link expires in 30 minutes.

4. Error — invalid email

Error

User submitted before email validates. Inline error; input is aria-invalid; focus returned to input.

Please enter a valid email address (e.g. you@example.com).

5. Error — network

Error

Submit reached server-side / network failure. Form remains usable; retry button labelled "Try again".

Couldn't send the link. Network error — check your connection and try again. If this keeps happening, email hello@ai-daily-digest.example.
