Sync-favourites flow — 4 states

The "Save these across devices" prompt on /favourites. Anonymous user with localStorage saves; flow links the device to an email so favourites follow them. Test IDs preserved from per-state mockups 13–16.

1. Prompt collapsed

Entry point

At rest on /favourites — the "Sync" button is visible. Spec B §D5 L145.

Save these across devices →

Link them to your email so they follow you to your phone and laptop.

2. Open — email input

Transition

User clicked "Sync"; prompt expanded with email input + "Send link" button.

Save these across devices

Enter your email — we'll send a one-click link to link this device.

3. Link sent (success)

Success

Form submit succeeded. Prompt replaced with confirmation showing the email + 30-min expiry note.

✓ Check your inbox

We sent a one-click link to alex@example.com. Click it within 30 minutes to sync your favourites.

4. Error

Error

Submit failed (network or invalid email). Form stays open with email retained; retry button.

Save these across devices

Enter your email — we'll send a one-click link to link this device.

Couldn't send the link. Network error — please try again. If this keeps happening, your favourites stay safe on this device.
